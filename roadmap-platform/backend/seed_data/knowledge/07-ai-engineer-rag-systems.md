# AI Engineer and RAG Systems

## Overview
AI engineering is the practice of building product features on top of models, embeddings, retrieval, prompts, agents, and evaluation loops. roadmap.sh’s AI Engineer roadmap includes LLMs, inference, training, embeddings, vector databases, RAG, prompt engineering, safety, agents, and multimodal AI. [web:23][web:16]

## What an AI engineer does
An AI engineer connects model capabilities to real application needs. That means choosing the right model, shaping prompts, managing context, orchestrating tools, evaluating outputs, and shipping features safely.

## LLM fundamentals
Learn the basics of tokens, context windows, latency, cost, sampling, temperature, and model limitations. The AI Engineer roadmap explicitly includes inference, token counting, pricing considerations, and prompt engineering. [web:23]

## Retrieval-Augmented Generation
RAG combines retrieval with generation so the model can answer from relevant external knowledge. Learn chunking, embeddings, vector databases, metadata filtering, reranking, prompt construction, and citation-aware response design.

## Prompt engineering
Study instruction clarity, role formatting, few-shot examples, structured outputs, and prompt debugging. Treat prompts as versioned artifacts that need testing and iteration.

## Tool use and agents
Learn function calling, tools, workflows, planning, and state management. roadmap.sh’s AI Engineer roadmap covers AI agents, ReAct prompting, OpenAI functions/tools, assistant APIs, and manual versus framework-based agent implementation. [web:23][web:19]

## Safety and evaluation
Understand prompt injection, bias, privacy, hallucination, and output validation. Evaluate systems with test sets, human review, automatic checks, and task-specific metrics.

## Multimodal systems
Explore image, audio, and video inputs when they matter for the product. roadmap.sh includes image understanding, generation, audio processing, speech-to-text, and text-to-speech in the AI Engineer roadmap. [web:23]

## Production concerns
AI features still need standard software concerns: authorization, logging, cost control, rate limiting, retries, fallbacks, and user-facing explanations. RAG systems in particular need good source quality and careful prompt boundaries.

## Milestones
1. Call a model API from a small app.
2. Add structured prompts and output validation.
3. Build a simple RAG pipeline over a document set.
4. Add tool use or agent behavior.
5. Add evaluation, safety checks, and production controls.
