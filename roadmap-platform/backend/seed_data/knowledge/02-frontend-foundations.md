# Frontend Foundations

## Overview
Frontend development focuses on the browser-side experience: structure, styling, interaction, accessibility, performance, and delivery. roadmap.sh frames frontend development around how the internet works, HTML, CSS, JavaScript, version control, package managers, build tools, frameworks, testing, TypeScript, PWAs, SSR/SSG, GraphQL, and even mobile or desktop extensions. [web:10][web:7]

## How the web works
Learn DNS, HTTP, browser rendering, domain names, hosting, caching, and how assets are fetched and displayed. This knowledge makes it easier to reason about layout bugs, network issues, hydration problems, and performance bottlenecks.

## HTML
Master semantic HTML first. Use proper document structure, headings, forms, buttons, landmarks, validation, and SEO-friendly markup so the browser, search engines, and assistive technologies all receive the right signals.

## CSS
Learn the box model, cascade, specificity, layout systems, responsive design, Flexbox, Grid, media queries, and modern utility or framework approaches such as Tailwind or Bootstrap. roadmap.sh includes CSS frameworks and preprocessors such as Sass and PostCSS as part of the frontend path. [web:10]

## JavaScript
Study syntax, scope, data types, functions, modules, DOM manipulation, events, Fetch/AJAX, async/await, and state management patterns. JavaScript is the core interaction layer of the modern web application.

## Version control and workflow
Use Git and a hosting platform such as GitHub, GitLab, or Bitbucket to manage collaboration, branches, pull requests, and releases. Good frontend work includes disciplined commits, issue tracking, and reproducible builds.

## Package managers and tooling
Understand npm, yarn, or pnpm, plus scripts, bundlers, linters, and formatters. Build tooling is how modern frontend projects remain maintainable as complexity grows.

## Frameworks and rendering models
Learn one major framework well, such as React, Vue, Angular, or Svelte. After that, study SSR and SSG with tools like Next.js, Nuxt.js, or Astro so you can choose the right rendering strategy for the product.

## Testing
Use unit tests for components and utilities, and end-to-end tests for user flows. roadmap.sh includes Jest, Vitest, Cypress, and Playwright in the frontend roadmap. [web:10]

## TypeScript
TypeScript is the default language for large frontend codebases because it improves maintainability, editor support, and API safety. Use it to model component props, server responses, and domain logic.

## Accessibility and quality
Accessibility is not optional: use semantic markup, keyboard support, sensible focus states, contrast-aware color choices, and screen-reader-friendly labels. Also pay attention to performance, bundle size, and visual stability.

## Advanced frontend topics
Once the fundamentals are solid, learn PWAs, service workers, offline storage, WebSockets, GraphQL clients, mobile wrappers such as React Native or Flutter, and desktop runtimes such as Electron. roadmap.sh includes all of these as part of the path from beginner to more advanced frontend work. ## Milestones
1. Build a responsive static site.
2. Add interactivity with JavaScript and forms.
3. Rebuild it in a framework with TypeScript.
4. Add testing, routing, and API integration.
5. Add SSR/SSG and performance optimization.
